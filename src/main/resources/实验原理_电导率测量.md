# 电磁阻尼法测量材料电导率 — 物理原理

## 一、实验装置

- 倾斜导轨（倾角 θ），滑块沿导轨下滑
- 滑块下方嵌入永磁体，导轨底部铺设导电垫板
- 滑块运动时，磁体在导电板中感应涡流，产生电磁阻尼力
- 通过测量滑块运动学参数（加速度、速度）反推垫板材料的电导率 σ

## 二、物理推导

### 2.1 动力学分析

设滑块质量为 m，重力加速度为 g，斜面倾角为 θ，动摩擦力为 f_k，电磁阻尼力为 F_d。

**释放瞬间（v = 0）：**

- 涡流尚未形成，电磁阻尼力 F_d = 0
- 牛顿第二定律：m·a₀ = m·g·sinθ − f_k
- 其中 a₀ = g·sinθ（释放瞬间实测加速度）
- 此时可通过测量 a₀ 替代对 mgsinθ−f_k 的求解，无需单独测定 θ 和 μ

**匀速阶段（a = 0）：**

- 当滑块达到终端速度 v∞ 时，合力为零
- m·g·sinθ − f_k − F_d(v∞) = 0
- 由释放瞬间关系得：F_d(v∞) = m·a₀

### 2.2 电磁阻尼力（楞次定律推导）

根据法拉第电磁感应定律和欧姆定律，磁场 B 在导电板中感应的涡流产生的阻尼力为：

```
F_d = σ · B² · d · A · v
```

其中：

- σ — 导电板材料的电导率（S/m）
- B — 磁感应强度（T）
- d — 导电垫板厚度（m）
- A — 磁体与导电板有效接触面积（m²）
- v — 滑块瞬时速度（m/s）

### 2.3 电导率反推公式

由匀速条件 F_d(v∞) = m·a₀，代入电磁阻尼表达式：

```
σ · B² · d · A · v∞ = m · a₀
```

解得电导率：

```
σ = m · a₀ / (B² · d · A · v∞)
```

## 三、数值验证（30° 斜面）

实验参数：

- m = 0.03 kg
- g = 9.81 m/s²
- θ = 30° → a₀ = g·sin30° = 4.905 m/s²
- B = 0.5 T
- d = 0.02 m
- A = 2 × 10⁻⁵ m²
- v∞ = 0.981 m/s（终端速度）

代入公式：

```
σ = (0.03 × 4.905) / (0.5² × 0.02 × 2×10⁻⁵ × 0.981)
  = 0.14715 / (9.81 × 10⁻⁸)
  ≈ 1.50 × 10⁶ S/m
```

对照金属电导率表：

- 不锈钢 304：σ ≈ 1.45 × 10⁶ S/m ← 最接近
- 铝：σ ≈ 3.50 × 10⁷ S/m ← 数量级差异

结论：检测材料为不锈钢 304

## 四、核心创新点

1. **免测角度与摩擦系数**：通过测量 a₀（释放瞬间加速度）替代 mgsinθ−f_k，无需单独测量斜面倾角 θ 和摩擦系数 μ
2. **非接触测量**：通过运动学参数间接反推材料电导率，不破坏被测材料
3. **物理自洽性**：三阶段运动模型（加速减弱 → 匀速 → 正弦刹车）保证位移-速度-加速度三重积分一致性
